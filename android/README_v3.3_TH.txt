ASCENT Fitness RPG v3.3 — DAILY QUEST REDESIGN
Updated: 2026-10-26

ไฟล์นี้เป็นการอัปเดตจาก v3.2 ไม่ใช่โปรเจ็กต์ใหม่
- หน้า Home / Quest: ดีไซน์แนว Daily Quest, เปอร์เซ็นต์รวม, แสดงภารกิจถึงเวลาจริง, แสดงวัตถุดิบละเอียด, ปุ่มทำสำเร็จ/ข้าม
- เครื่องหมายช่องใน GOALS ใช้เช็กการเตรียมวัตถุดิบเท่านั้น ไม่หักคลังจนกดยืนยัน “กินแล้ว”
- QUEST COMPLETE: popup + particle จาก canvas + เสียง + EXP โดยใช้ระบบบันทึกเดิม
- เสียงเกม 3 ประเภท: ปุ่ม, สำเร็จ, ข้าม; เลือกไฟล์เองได้แยกอิสระใน ตั้งค่า > เสียงปุ่มและรางวัล
- คลิกเสียงใช้เสียงสังเคราะห์หากไม่เลือกไฟล์; เลือก WAV/MP3/OGG/M4A ไม่เกิน 3 MB / ไฟล์
- ปรับคะแนน EXP จากเควสน้ำเป็น +3 ต่อครั้ง (ครบเป้าโบนัส +2) รวมต่อวัน 20 EXP เท่าเดิม
- สไตล์ shell v3.2 ถูกแทนเป็น v3.3 ไม่มีการแทรก CSS ชุด v3.2 ทับซ้อน; CSS v3.1 ยังคงอยู่สำหรับฟอร์มและหน้ารอง
- ไม่แก้คีย์ข้อมูล localStorage: ascent_fitness_v1; สำรอง JSON ก่อนอัปเดตเสมอ

ติดตั้ง WEB บน Firebase Hosting:
1. แตก zip "WEB" เอาเนื้อหาใน web/ ไปไว้ public/ascent/
2. รัน firebase deploy --only hosting
3. เปิด https://<project>.web.app/ascent/ แล้วรีโหลดหนึ่งครั้งหากมี SW version ก่อนหน้า
4. เปิด ตั้งค่า > เสียงปุ่มและรางวัล เพื่อเลือกเสียงตามที่ต้องการ

Android Native:
- โค้ดใน android/ เป็น source สำหรับ Android Studio ไม่ใช่ APK ที่คอมไพล์แล้ว
- หน้า WebView ที่แสดงผ่าน Android มีเสียงปุ่ม/สำเร็จ/ข้ามตอนแอปเปิดอยู่
- ตั้งเสียงเตือนเควสเบื้องหลังผ่าน "แจ้งเตือนและเสียงเควส" แยกจากเสียงในเกม
- วิดเจ็ตและ GPS เบื้องหลังใช้โครง Native เดิมจาก v3.2 ยังไม่ได้ยืนยันบนโทรศัพท์จริง
- PWA อย่างเดียวไม่รับประกัน GPS/เสียงเตือนขณะปิดหน้าจอ

การทดสอบที่ทำ:
- node --check ผ่าน
- ทดสอบ Chromium ความกว้าง 360, 390, 768, 1440 px; สลับหน้า Home, Food, Pantry, Quest, Run, Stats, Settings ไม่มี JS error และไม่มี horizontal overflow
- เติมคลัง -> แสดงอาหารตามวัตถุดิบ -> กดกินแล้ว -> popup QUEST COMPLETE ปรากฏ
- ทดสอบการเปิดหน้าเสียง 3 ประเภท (ไม่ได้ยืนยันการเล่นไฟล์เสียงจริงบน Android)
- ไม่ได้ทดสอบ Android build จริง / OCR ใบเสร็จจริง / ความแม่นยำ GPS ในชีวิตจริง
